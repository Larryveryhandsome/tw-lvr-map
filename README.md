# tw-lvr-map｜實價登錄地圖

把內政部「實價登錄」開放資料畫成**互動地圖**：一眼看出哪裡成交、多少錢，還能篩選、算中位數、匯出 Excel。

- **地圖**：每筆交易一個點，顏色代表單價高低（依目前資料的四分位數），點多時自動群聚
- **篩選**：行政區、建物型態、交易日期、總價、單價、建坪、屋齡、關鍵字（路名、社區）
- **排除特殊交易**：備註有親友、特殊關係、瑕疵、債權等字眼的，預設不列入，比價更準
- **統計**：筆數、單價中位數／平均（萬／坪）、總價中位數、各區單價中位數
- **列表**：可排序；**匯出 CSV**（Excel 開不亂碼）；**複製分享連結**（篩選條件存在網址裡）
- 純網頁，免伺服器，可以放 GitHub Pages

**線上示範（虛構資料）：** https://larryveryhandsome.github.io/tw-lvr-map/

> ⚠️ 線上示範與專案裡附的資料都是 `tools/make_sample.py` **隨機產生的虛構資料**（「示範○區示範路」），只是借用真實地圖當底圖，**不代表任何真實行情**。要看真實行情，請照下面步驟下載政府開放資料自己轉。
>
> 實價登錄為政府公開資料的整理與視覺化，原則上僅供行情參考；個案價格受樓層、屋況、車位與交易條件影響，不構成估價或投資建議。

## 需要哪些金鑰？

**不需要。** 實價登錄開放資料免費下載、免金鑰；地圖底圖用 OpenStreetMap。
只有在轉換時加 `--geocode`（把門牌轉成精確座標）需要填一個**你自己的 Email**（`--email`），這是 OpenStreetMap Nominatim 使用規範要求的聯絡方式，不是金鑰、不收費，只會放在查詢的 User-Agent 裡。

## 用真實資料做你的城市版本

**需要：** Python 3.9 以上（只用標準庫，不用安裝套件）。

### 1. 下載政府開放資料

1. 到 [內政部不動產交易實價查詢服務網 → 開放資料下載](https://plvr.land.moi.gov.tw/DownloadOpenData)。
2. 選「本期下載」（或歷史資料）→ 格式選 **CSV** → 勾你要的縣市的「**不動產買賣**」→ 下載。
3. 解壓縮後找到像 `a_lvr_land_a.csv` 的檔案（第一個字母是縣市代碼，例如 `a` 是臺北市；結尾 `_a` 是不動產買賣）。

> 授權：[政府資料開放授權條款－第 1 版](https://data.gov.tw/license)，可自由利用，**需標示出處**（轉換程式會自動在頁面上寫出處）。

### 2. 設定行政區中心點（建議）

打開 `districts.json`，把示範的「示範○區」換成你下載的縣市的行政區與中心座標（緯度、經度，可以在 Google 地圖按右鍵複製）。
沒有精確座標的交易會放在中心點附近，地圖上用**虛線圈**標成「約略位置」。

### 3. 轉換

```bash
python tools/convert_open_data.py a_lvr_land_a.csv --title "臺北市實價登錄地圖" --only-buildings --out data.js
```

- 可以一次放好幾個 CSV（例如好幾季）。
- `--only-buildings`：只留有建物的交易（排除純土地、純車位）。
- `--since 2024-01-01`（或民國 `1130101`）：只留這個日期之後的交易。
- 好幾份 CSV 的期間重疊時，相同「編號」只留一筆，不會重複計算。
- 檔案是 UTF-8 或 Big5 都讀得懂；欄位缺了「鄉鎮市區、交易年月日、總價元、土地位置建物門牌」（例如下載到預售屋、租賃的 CSV）會直接告訴你，不會默默轉出空資料。
- **資料量**：轉換是逐列處理（50 萬列實測約 22 秒、記憶體約 70MB），但產生的 `data.js` 會很大（50 萬列約 230MB），瀏覽器載入會很慢甚至當掉。原則上建議單一網頁控制在 10 萬筆以內（加 `--only-buildings`、`--since`，或分縣市／分區各做一份）。轉換結果超過 10 萬筆或 40MB 時程式會提醒。地圖一次最多畫最近成交的 5000 個點，統計、列表與匯出 CSV 仍是全部符合條件的資料。
- 網頁預設只統計「有建物」的交易（純土地、純車位的單價意義不同，混在一起會拉歪中位數），要看土地行情請取消勾選。

**想要精確到門牌的位置**（比較慢，每秒 1 筆）：

```bash
python tools/convert_open_data.py a_lvr_land_a.csv --geocode --email 你的信箱 --county 臺北市 --out data.js
```

這會用 [OpenStreetMap Nominatim](https://nominatim.org/) 把門牌轉成座標，依它的[使用規範](https://operations.osmfoundation.org/policies/nominatim/)每秒最多 1 筆、帶上你的聯絡信箱，結果快取在 `data/geocode_cache.json`，下次不會重查。幾千筆會跑很久，建議先用 `--only-buildings` 縮小範圍。

### 4. 打開

雙擊 `index.html` 就能看。要放上網：整個資料夾丟到 GitHub Pages 或任何靜態網站空間。

## 欄位換算

| 網頁欄位 | 開放資料欄位 | 換算 |
|---|---|---|
| 總價（萬） | 總價元 | ÷ 10,000 |
| 單價（萬／坪） | 單價元平方公尺 | × 3.305785 ÷ 10,000（政府資料的單價已扣除車位） |
| 建坪 | 建物移轉總面積平方公尺 | ÷ 3.305785 |
| 交易日期 | 交易年月日（民國） | 轉西元 |
| 屋齡 | 建築完成年月 → 交易日 | 以月計算 |
| 樓層 | 移轉層次、總樓層數（國字） | 轉數字；地下樓層為負數 |

## 給開發者

|---|---|
| `index.html` | 頁面（Leaflet、markercluster 從 cdnjs 載入，含 SRI） |
| `js/lvr.js` | 純函式：篩選、統計、排序、分級、CSV、網址參數 |
| `js/app.js` | 地圖、篩選欄、列表 |
| `tools/convert_open_data.py` | 開放資料 CSV → `data.js`（含 Nominatim 定位與快取） |
| `tools/make_sample.py` | 產生虛構示範資料 |

```bash
npm test
```
